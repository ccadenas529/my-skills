# Corporate Presentation

## Always start from the template
Use the file `template.pptx` in this folder. Build every deck from its
layouts. Never create slides from a blank presentation.

## Brand rules
- Fonts: [heading font], [body font]
- Colors: primary [hex], secondary [hex], accent [hex]
- Logo: [where it goes, never stretch or recolor it]
- Tone: [e.g. clear, professional, no jargon]

## Layouts in the template
| Layout name | Use it for |
|---|---|
| [Title Slide] | Opening slide |
| [Section Header] | Dividing sections |
| [Title and Content] | Main points |
| [Two Content] | Comparisons |
| [Closing] | Final slide |

## Structure of a deck
1. Title slide
2. Agenda (for decks over 6 slides)
3. Content slides: one message per slide, maximum 5 bullets
4. Summary or next steps
5. Closing slide

## Rules
- Slide titles state the takeaway, not just the topic.
- No more than [40] words per slide.
- Use tables or charts instead of long text when comparing data.
- Never invent numbers, names, or dates. Leave a clear placeholder.
- Keep speaker notes brief and only if the user asks.
