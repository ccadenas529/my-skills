# Meeting Summary


## Steps
1. Read the full notes before writing anything.
2. Write a 2-3 sentence overview of the meeting's purpose and outcome.
3. List decisions made, one line each.
4. List action items as: Person, task, deadline (write "no date given" if missing).
5. Note open questions that were left unresolved.

##Style
- Plain, direct language. No filler.
- Keep it under one page.
- Never invent names, dates, or decisions that aren't in the notes.
