# Meeting Summary

## Steps
1. Read the full notes before writing anything.
2. Produce the output in the format below.
3. If the user asks for a visual or polished version, create it as a clean one-page HTML page (or a Word/PDF file if they request one).

## Output format

### Overview
2-3 sentences: purpose and outcome of the meeting.

### Meeting details
| Field | Detail |
|---|---|
| Date | |
| Attendees | |
| Topic | |

### Decisions
| # | Decision | Owner |
|---|---|---|

### Action items
| Priority | Task | Owner | Deadline | Status |
|---|---|---|---|---|

Use 🔴 High, 🟡 Medium, 🟢 Low for priority. Use "No date given" if a deadline is missing.

### Open questions
| Question | Who should answer |
|---|---|

## Visual version (when requested)
- One page, clean layout, plenty of white space.
- Color-code priority (red, amber, green).
- Put the overview at the top, action items in the middle, open questions at the bottom.
- Use a simple chart only if there is real data to show, such as tasks per person.

## Rules
- Never invent names, dates, or decisions that aren't in the notes.
- Keep the whole summary to one page.
- Leave a cell blank rather than guessing.
